LOCAL SKY STUDIO — WEBSITE OWNER GUIDE

Created by Dean Freeman
Contact: deanfreeman9@gmail.com

SOURCE REPOSITORY

https://github.com/DeanFreeman9/local-sky-studio

The repository contains the website source. GitHub Pages publishes only the
contents of the public folder through the deployment workflow.

PUBLISH AN UPDATE

1. Edit and test the files in the public folder.
2. Commit the changes to Git.
3. Push the main branch to GitHub.
4. The GitHub Pages workflow deploys the new website automatically.
5. Check the Actions tab if a deployment does not complete.

There is no installer, executable, desktop updater, Node server or localhost
step. Visitors receive the newest deployed version when they refresh the site.

PRIVACY

The source repository is private, but a normal GitHub Pages website is publicly
reachable. Anyone with the website address can use it and can forward the link.
Restricting the website to approved people requires a separate authenticated
hosting service; a private source repository by itself does not restrict access
to the published Pages website.
